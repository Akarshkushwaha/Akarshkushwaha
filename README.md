## 🚀 Highlighted Engineering 

> **[Verto](https://github.com/Akarshkushwaha/verto) — Automated GitHub PR Risk Guard**  
> Native GitHub App that catches critical deployment risks before code merges. Powered by concurrent FastAPI webhook pipelines and LLaMA 3 to post automated risk summaries directly into PR comments.

> **[Recon](https://github.com/Akarshkushwaha/Recon) — Real-Time Git Conflict & AI Standup**  
> A real-time conflict detection platform mapping live Git branch activity via webhooks to prevent code overlaps before PRs. Integrates Gemini 2.0 and LLaMA 3.3 for seamless automated standups and PR drafting.

> **[Capi](https://github.com/Akarshkushwaha/Capi) — Autonomous .env Config Guardrail**  
> An autonomous configuration guardrail connecting mystery `.env` variables directly to Git commits and PR discussions. Eliminates configuration guesswork and prevents catastrophic production crashes.

> **[Study Mitra](https://github.com/Akarshkushwaha/) — Intelligent Study Companion**
